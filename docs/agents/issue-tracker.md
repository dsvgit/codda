# Трекер задач: локальный Markdown

Задачи и спеки этого репозитория хранятся как markdown-файлы в `.scratch/`.

## Соглашения

- Одна фича — одна директория: `.scratch/<feature-slug>/`
- Спека — `.scratch/<feature-slug>/spec.md`
- Задачи на реализацию — по одному файлу на тикет: `.scratch/<feature-slug>/issues/<NN>-<slug>.md`, нумерация с `01`; никогда не сводить тикеты в один общий файл
- Шапка тикета: `# NN: <название>`, затем строки `**What to build:**`, `**Blocked by:**` (`None (can start immediately)` или номера), `**Status:**`, затем чекбоксы критериев приёмки
- Статусы (`**Status:**` у тикета, у спеки — в её шапке):
  - `ready-for-agent` — можно брать в `/implement`
  - `in-progress` — агент взял тикет; ставится до начала работы
  - `ready-for-human` — агент сделал всё, что мог; остался шаг только для человека (демо, решение). Что именно — в `## Comments`
  - `done` — все чекбоксы отмечены, тесты зелёные, работа закоммичена. Ставит агент в конце `/implement`
- Комментарии и история дописываются в конец файла под заголовком `## Comments`: запись начинается с `**YYYY-MM-DD — <что> (<кто>).**`, в конце — список «Не протестировано (на отдельный проход)»
- Отклонения от спеки фиксируются в `## Comments` тикета; спека задним числом не переписывается. Итог стадии — раздел `## Итог` в конце спеки

## Когда скилл говорит «опубликовать в трекер»

Создать новый файл в `.scratch/<feature-slug>/` (создав директорию, если её нет).

## Когда скилл говорит «получить нужный тикет»

Прочитать файл по указанному пути. Обычно пользователь передаёт путь или номер тикета напрямую.

## Операции wayfinding

Используются `/wayfinder`. **Карта** — это файл, у которого есть по одному **дочернему** файлу на каждый тикет.

- **Карта**: `.scratch/<effort>/map.md` (разделы Notes / Decisions-so-far / Fog).
- **Дочерний тикет**: `.scratch/<effort>/issues/NN-<slug>.md`, нумерация с `01`, вопрос — в теле файла. Строка `Type:` задаёт тип тикета (`research`/`prototype`/`grilling`/`task`); строка `Status:` — `claimed`/`resolved`.
- **Блокировка**: строка `Blocked by: NN, NN` в начале файла. Тикет разблокирован, когда все перечисленные в ней файлы имеют статус `resolved`.
- **Frontier** (доступные тикеты): просканировать `.scratch/<effort>/issues/` и найти открытые, разблокированные и никем не взятые тикеты; берётся первый по номеру.
- **Взять тикет**: выставить `Status: claimed` и сохранить файл до начала любой работы.
- **Закрыть тикет**: дописать ответ под заголовком `## Answer`, выставить `Status: resolved`, затем добавить ссылку с кратким выводом (суть + ссылка) в раздел Decisions-so-far файла `map.md`.
