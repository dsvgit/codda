# npm-зависимости — заранее собранные в CI Dependency Artifacts, а не npm install в браузере

Lesson Manifest перечисляет зависимости с точными версиями; CI ставит их из внутреннего npm registry, проверяет browser-совместимость, собирает в ESM и публикует неизменяемые артефакты по content-hash. Браузер получает только готовые артефакты и никогда не резолвит npm сам. Это убирает из браузера резолвинг CJS/ESM/exports, делает Run воспроизводимым и соответствует ADR-0002.

## Consequences

- Студент не может добавить произвольный пакет — только то, что объявил Author.
- Нужен отдельный CI-пайплайн (roadmap, блок B): CommonJS → ESM, package exports, subpath imports, CSS/JSON, `.d.ts`, peer/shared deps, кэширование.
- В PoC пайплайна нет: артефакты (`react`, `react-dom`) собираются локальным скриптом и кладутся в репозиторий.
