# Сначала проверка только в браузере, Server Grader — позже и только по необходимости

Lesson Tests выполняются в Sandbox на стороне студента; Server Grader (изолированная VM, Hidden Tests) не входит ни в PoC, ни в MVP. Браузерной проверки достаточно для учебной обратной связи, а серверная инфраструктура исполнения — дорогая и рискованная часть, которую мы добавим, только если понадобятся Hidden Tests, защита от списывания, Node/FS/DB/сеть или серверные фреймворки.

## Consequences

- Run и Submit — разные понятия (см. CONTEXT.md); в MVP есть только Run.
- Результат Run не является доказательством решения: студент технически может подделать Test Report.
