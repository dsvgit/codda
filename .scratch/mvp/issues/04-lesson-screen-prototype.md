# 04: Раскладка экрана Lesson и тулбар

Type: prototype
Status: resolved
Blocked by: None

## Question

Как выглядит и ведёт себя экран Lesson в MVP? Сделать грубый прототип и решить на нём.

Уже решено: весь UI на русском (кнопка «Run tests» тоже получает русское название); у действий нет подтверждений; один файл Workspace (без табов и дерева).

На экране: Instructions (Markdown), редактор с TS-diagnostics, тулбар (Запустить тесты, Отмена, Reset, Показать Solution, Предыдущий/Следующий Lesson), Test Report, console студента, список Lesson Course с отметками о прохождении.

Решить: расположение панелей, что делает «Показать Solution» (заменяет Workspace, открывает рядом, только для чтения?), как выглядит Test Report с console и ошибкой компиляции, где виден прогресс.

## Answer

Вопросы и ответы — в [questions/04-lesson-screen-prototype.md](../questions/04-lesson-screen-prototype.md). За основу взят вариант A прототипа («IDE»).

- **Раскладка:** три колонки. Слева сворачиваемое дерево Course, в центре Instructions, справа тулбар, редактор Workspace и нижняя панель. Instructions, код и результат видны одновременно.
- **Тулбар** — одна строка над редактором: `▶ Запустить тесты` · `↺ Сбросить` · `Показать решение` ‖ `← Предыдущий` · `Следующий →`. Во время Run на месте «Запустить тесты» стоит `■ Отмена`. В UI Solution называется «решение»; термины `CONTEXT.md` остаются для кода и документации.
- **Нижняя панель** — вкладки `Тесты` · `Console` · `Проблемы` · `Решение`. На вкладках счётчики: `2/3` (зелёный или красный), число строк console, число проблем. После Run открывается «Тесты».
- **Solution:** вкладка «Решение» в нижней панели. Редактор там только для чтения, Workspace над ним не меняется, поэтому код и эталон видны одновременно. «Показать решение» в тулбаре открывает эту вкладку, отдельной кнопки «Скрыть» нет: студент просто переключает вкладку. Кнопки «скопировать решение в редактор» нет.
- **Test Report:** список тестов с ✓/✗ и текстом ошибки, итог `PASS`/`FAIL · N / M`. При PASS — зелёный баннер с кнопкой «Следующий урок →». Ошибка компиляции, runtime-ошибка и timeout показываются во вкладке «Тесты» вместо списка: красный заголовок и `Строка N:M — сообщение`. Строка ошибки компиляции ещё и подчёркивается в редакторе.
- **Прогресс:** в дереве Course — ✓ у пройденных Lesson и «Пройдено N из M» с полоской. Lesson пройден, когда хотя бы один Run дал PASS по всем тестам. Отметка сохраняется после Reset и при сломанном коде.
- **Reset** без подтверждения — обычная транзакция редактора, `Ctrl/Cmd+Z` его откатывает.
