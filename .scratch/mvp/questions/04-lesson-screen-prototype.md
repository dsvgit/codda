# Раскладка экрана Lesson и тулбар — вопросы

Решения по тикету [04: Раскладка экрана Lesson и тулбар](../issues/04-lesson-screen-prototype.md) на основе прототипа. Ответ пишите под строкой «**Ответ:**». Пустой ответ означает, что вы согласны с рекомендацией. Можно отвечать сборкой из частей: «раскладка из A, Test Report из C».

## Как посмотреть прототип

Ветка `prototype/lesson-screen` (throwaway, в `main` не мержится):

```sh
git switch prototype/lesson-screen
npm run dev
# http://localhost:5173/?variant=A   (B, C; ?lesson=react-hooks/02-use-effect тоже работает)
```

Внизу экрана плавающая панель. Стрелки `‹ ›` (или клавиши ← →) переключают варианты, а ряд «Test Report» подставляет состояния: идёт Run, PASS, FAIL, ошибка компиляции, runtime, timeout. «Запустить тесты» делает настоящий Run на runtime из PoC. Console и TS-diagnostics имитированы: console пока не перехватывается, а вместо diagnostics подчёркивается неиспользованный импорт из `react`. Прогресс и Workspace хранятся только в памяти.

| | A · IDE | B · Учебник | C · Вкладки |
|---|---|---|---|
| Раскладка | дерево Course · Instructions · редактор, три колонки | одна колонка: Instructions → редактор → лог | слева вкладки, справа редактор |
| Тулбар | над редактором, все действия в одну строку | под редактором; Пред./След. внизу страницы | Пред./След. в шапке, Run и Reset — плавающие кнопки на редакторе |
| Solution | рядом с Workspace, только чтение | заменяет Workspace в том же редакторе, баннер «Вернуться к своему коду» | отдельная вкладка слева, только чтение |
| Test Report | нижняя панель, вкладки Тесты / Console / Проблемы | один лог в порядке Run: console, затем тесты | вкладка «Результат»: крупный баннер PASS/FAIL, тесты, свёрнутая console |
| Прогресс | дерево с ✓ и «Пройдено N из M» | сегментный прогресс-бар + выпадающий список | степпер кружков в шапке |

### Q3 — Test Report, console и ошибка компиляции

- Тесты, console и TS-diagnostics («Проблемы») — отдельные вкладки нижней панели (A). После Run открывается «Тесты». На вкладках счётчики: `2/3` красным или зелёным, число строк console, число проблем.
- Ошибка компиляции, runtime и timeout показываются во вкладке «Тесты» вместо списка тестов: красный заголовок и `Строка N:M — сообщение`. Строка ошибки компиляции ещё и подчёркивается в редакторе.
