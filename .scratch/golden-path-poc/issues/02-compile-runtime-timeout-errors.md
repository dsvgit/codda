# 02: Ошибки компиляции, runtime-ошибки и timeout

**What to build:** студент, сломавший код, всегда получает понятный Test Report вместо зависшей или упавшей страницы. Синтаксическая/типовая ошибка esbuild → `compile-error` со строкой и колонкой. Исключение на верхнем уровне модуля студента → `runtime-error`. Бесконечный цикл → `timeout` через 5 с, Sandbox уничтожается, следующий Run работает без перезагрузки страницы.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] `compile-error` с message/line/column отображается в UI
- [ ] `runtime-error` (throw вне теста, ошибка импорта) отличается в UI от проваленного теста
- [ ] `while(true){}` в коде студента → `timeout`, UI остаётся отзывчивым
- [ ] После timeout следующий Run возвращает корректный результат
- [ ] Повисший Worker (если компиляция не вернулась) пересоздаётся
- [ ] Каждый сценарий покрыт браузерным тестом на шве Runner
