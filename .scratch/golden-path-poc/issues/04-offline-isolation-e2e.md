# 04: Доказательство offline и изоляции + e2e Golden Path

**What to build:** одна команда (`npm run test:e2e`) доказывает гипотезу целиком: Playwright открывает страницу, жмёт Run → видит FAIL, вставляет Solution в редактор → Run → «3 / 3 passed». Всё это — в контексте, где любой запрос не на localhost блокируется и валит тест. Плюс проверки изоляции Sandbox из ADR-0003.

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] e2e Golden Path: FAIL → правка → PASS
- [ ] Тот же сценарий с блокировкой внешней сети; список всех сетевых запросов страницы логируется, внешних — ноль
- [ ] Тест: код студента, пытающийся прочитать `parent.document`, `document.cookie`, `localStorage`, получает ошибку/пустоту, а не данные приложения
- [ ] Тест: Sandbox, присылающий сообщения чужой формы или с чужим `runId`, не меняет UI
- [ ] Поддельный `fetch("https://example.com")` из кода студента не проходит (фиксируем фактическое поведение — блокировка тестом/CSP-заголовком dev-сервера)
