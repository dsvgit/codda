# 03: Дерево Course слева

**What to build:** Слева от Instructions появляется колонка с деревом Course (раскладка «IDE» из тикета 04 Плана решений): название Course, Module заголовками, под каждым — его Lesson по порядку `course.yaml` с `title` из frontmatter. Lesson — ссылка `#/<lesson id>`, клик открывает его через тот же механизм фрагмента, что тикет 01. Текущий Lesson выделен и помечен `aria-current="page"`. Кнопка `«` сворачивает дерево в узкую полосу, `»` разворачивает; состояние не сохраняется и живёт до перезагрузки. Module сами не сворачиваются. Прогресс (✓, «Пройдено N из M») добавляет тикет 04. См. [спеку](../spec.md).

## Comments

- Дерево — `CourseTree` в `App.tsx`: `<nav aria-label="Уроки курса">`, название Course — `h2`, Module — `h3` и `<ol aria-label="<title Module>">`, Lesson — `<a href="#/<id>">` (`encodeURIComponent`, как у `go`). Клик — обычный переход по ссылке-фрагменту: новая запись в истории и `hashchange`, дальше механизм тикета 01; своего обработчика клика нет. `aria-current="page"` и выделение (фон, синяя полоса слева) — у Lesson из фрагмента, поэтому переезжают при тулбаре, баннере и «Назад» без отдельного кода.
- Свёрнутость — `useState` в `App` (не в `Lesson`, который пересоздаётся на каждый Lesson): держится при переходах, сбрасывается перезагрузкой. Дерево рисует `Lesson` первой колонкой своей сетки (`tree` — проп), колонка на всю высоту, заголовок `h1` над Instructions и правой частью. Свёрнутое дерево — полоса 36px с одной кнопкой `»`, Lesson не рендерятся. Кнопки `«`/`»` — `aria-label` и `title` «Свернуть/Развернуть список уроков».
- Дерево только на экране Lesson: экраны ошибок `codda dev` («Ошибки в Lesson», «Ошибки в курсе») его не показывают — не в критериях, а их тесты ищут `listitem` по всей странице. Lesson с ошибками (`BrokenLesson`) в дереве есть, под своим id.
- Ширина дерева 200px, а не больше: при 1280×800 с деревом 230px тулбар (5 кнопок, `nowrap`) вылезал за правый край на ~12px — тесты «всё на экране при 1280×800» и «кнопки навигации справа» краснели. С 200px запас ~8px; длиннее подписи кнопок тулбара на 1280 уже не влезут.
- Тесты: компонентные в `App.test.tsx` — фикстура из двух Module (в первом два Lesson): заголовки, Lesson по Module и порядку, `href`, ровно один `aria-current`; клик по дереву (+1 запись в истории), `aria-current` после `← Предыдущий`, `Следующий →`, `history.back()`; свернуть → ссылок нет, Instructions и редактор шире, свёрнутость переживает переход, развернуть → ширина как была. Все три красные до кода. e2e — в `e2e/navigation.e2e.ts` (проекты `dev` и `pages`): клик по третьему Lesson → «useRef» и `#/use-ref`, свернуть → 0 ссылок → развернуть → 5; написан вместе с кодом, красным отдельно не прогонялся.
- Проверки: `npm run typecheck` зелёный; `npm test` — 243 passed, 1 skipped (17 файлов), без `CI=true`; `npm run test:e2e` — 60 passed.
