# 01: Переход между Lesson — адрес `#/…`, `← Предыдущий` / `Следующий →`, «Следующий урок →»

**What to build:** Студент ходит по Lesson Course, не трогая адресную строку. В тулбаре справа от `Показать решение` появляются `← Предыдущий` и `Следующий →`, они идут по всем Lesson всех Module в порядке `course.yaml`. В зелёном баннере PASS — кнопка «Следующий урок →», на последнем Lesson вместо неё текст «Это последний урок курса». Адрес открытого Lesson — фрагмент `#/<lesson id>`: каждый переход меняет фрагмент, экран слушает `hashchange` и меняет Lesson без перезагрузки страницы, поэтому «Назад»/«Вперёд» браузера, ссылка и перезагрузка открывают нужный Lesson. Пустой фрагмент и неизвестный id открывают первый Lesson Course и заменяют фрагмент на его id без новой записи в истории (тикет 04 этой фичи меняет это на «первый непройденный»). Переход — смена Lesson целиком: идущий Run отменяется, нижняя панель показывает новый Lesson, у редактора пустая история отмены, Type Checker проверяет новый Lesson. Workspace в этом тикете при уходе с Lesson теряется (сохранение — тикет 02). См. [спеку](../spec.md), раздел Implementation Decisions.

**Blocked by:** фичи `lesson-manifest`, `runtime-hardening`, `ts-tooling` целиком (порядок [autorun](../../README.md)).

**Status:** ready-for-agent

- [ ] Плоский порядок Lesson выводится из загруженного Course (все Module по порядку `course.yaml`); `← Предыдущий` / `Следующий →` в тулбаре ходят по нему, в том числе через границу Module
- [ ] `← Предыдущий` неактивна на первом Lesson, `Следующий →` — на последнем
- [ ] Баннер PASS содержит «Следующий урок →», которая открывает следующий Lesson; на последнем Lesson кнопки нет, есть текст «Это последний урок курса».
- [ ] Все переходы меняют только фрагмент `#/<lesson id>`; Lesson меняется по `hashchange` без перезагрузки страницы и без повторной загрузки `course.json`
- [ ] Пустой фрагмент (`#`, `#/`, без фрагмента) и неизвестный id открывают первый Lesson; фрагмент заменяется через `replaceState`, «Назад» не возвращает на пустой адрес
- [ ] Переход во время Run отменяет Run; результат отменённого Run не появляется ни в старом, ни в новом Lesson
- [ ] После перехода «Тесты», «Console», «Проблемы» и «Решение» относятся к новому Lesson; `Ctrl/Cmd+Z` не возвращает код прошлого Lesson; Type Checker подчёркивает ошибки нового Workspace с типами его Lesson Tests
- [ ] e2e (offline, проекты `dev` и `pages`): открыть Course → `Следующий →` → заголовок второго Lesson и фрагмент `#/<его id>` → Solution в редактор → Run → PASS → «Следующий урок →» → третий Lesson; «Назад» браузера возвращает на второй; перезагрузка остаётся на том же Lesson
- [ ] e2e: адрес без фрагмента и с `#/no-such-lesson` открывает первый Lesson, фрагмент — его id
- [ ] Компонентный тест экрана (фикстура из двух Module): переход через границу Module, неактивные кнопки на краях, текст в баннере на последнем Lesson, переход во время Run (Run отменён, нижняя панель пустая)
- [ ] `npm run typecheck`, `npm test`, `npm run test:e2e` зелёные
