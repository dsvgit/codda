# 04: Прогресс — ✓ у пройденных Lesson и «Пройдено N из M»

**What to build:** Lesson становится пройденным, когда Run дал PASS: Test Report вида «тесты», тестов ≥ 1, все прошли. Отметка пишется в `localStorage` ключом `codda:<course id>/<lesson id>:passed` со значением `"1"` и больше не снимается: Reset, сломанный код, FAIL, ошибка компиляции не трогают её. В дереве Course у пройденных Lesson ✓ (с доступным текстом «пройден»), над списком «Пройдено N из M» и полоска с `role="progressbar"`; M — Lesson в текущем `course.json`, N — пройденные из них, ключи удалённых Lesson не считаются. Адрес без Lesson и неизвестный id теперь открывают первый непройденный Lesson, а если пройдены все — первый. Хранилище — модуль из тикета 02, его ошибки обрабатываются так же: отметка живёт в памяти, видна та же строка предупреждения. См. [спеку](../spec.md).

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] Run с PASS ставит отметку Lesson, для которого Run был запущен (Lesson запоминается при старте Run); ✓ и «N из M» обновляются сразу
- [ ] Ошибка компиляции, runtime-ошибка, timeout, отменённый Run, FAIL и пустой список тестов отметку не ставят и не снимают; ошибки типов на отметку не влияют
- [ ] Отметка переживает Reset, последующий FAIL и перезагрузку
- [ ] Отметкой считается только значение `"1"`; любое другое значение ключа — «не пройден», экран не падает
- [ ] Ключ на каждый Lesson: запись отметки не читает и не переписывает отметки других Lesson
- [ ] «Пройдено N из M» и полоска считают только Lesson текущего Course; ключ Lesson, которого нет в `course.json`, не учитывается
- [ ] Пустой фрагмент и неизвестный id открывают первый непройденный Lesson (все пройдены — первый), фрагмент заменяется через `replaceState`
- [ ] При недоступном или полном `localStorage` отметка ставится в памяти страницы, показывается та же строка предупреждения, что в тикете 02
- [ ] e2e (offline, `dev` и `pages`): «Пройдено 0 из 5» → Solution → Run → PASS → ✓ у Lesson и «Пройдено 1 из 5» → Reset → перезагрузка → ✓ и «1 из 5» на месте; открыть адрес без Lesson → открыт второй Lesson
- [ ] Компонентный тест: ошибка компиляции и timeout не дают ✓; переход во время Run не отмечает ни старый, ни новый Lesson; испорченное значение `:passed`; ключ Lesson, которого нет в Course; `localStorage`, бросающий на записи — ✓ видна до перезагрузки
