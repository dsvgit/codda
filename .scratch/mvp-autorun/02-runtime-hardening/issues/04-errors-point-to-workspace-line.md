# 04: Ошибки указывают строку в файле Workspace

**What to build:** runtime-ошибка и проваленный тест, упавший на исключении в коде студента, показывают `Строка N:M — сообщение` в файле Workspace, а не stack бандла. Ошибка компиляции получает строку, только если она в Workspace, и подчёркивается в редакторе до следующей правки или Run; ошибка компиляции в Lesson Tests (например, переименованный экспорт) показывается без строки. Compiler отдаёт source map, Runner переводит первый кадр стека, попавший в Workspace, в `line/column` (свой маленький VLQ-декодер, декодирование лениво), `stack` уходит из публичного Test Report. Подчёркивание — через `@codemirror/lint`. Детали — в спеке, разделы «Source maps», «Ошибки компиляции», «Подчёркивание в редакторе».
