# 01: Отмена Run

**What to build:** пока идёт Run, на месте `▶ Запустить тесты` в тулбаре стоит `■ Отмена`. Нажатие сразу останавливает Run — и во время компиляции, и во время тестов: Sandbox уничтожается, зависшая компиляция прерывается вместе с Worker. Во вкладке «Тесты» нейтральное «Запуск отменён», кнопка снова «Запустить тесты», следующий Run работает без перезагрузки. Runner получает внешний `AbortSignal` и новый вид отчёта `cancelled`; deadline и отмена идут одним путём. См. спеку, разделы «Интерфейс Runner» и «Экран Lesson».

**Blocked by:** `lesson-manifest` (тулбар и нижняя панель экрана Lesson)

**Status:** ready-for-agent

- [ ] `run(input, { signal })`: отмена во время тестов (код студента `while (true) {}`) → `{ kind: "cancelled" }` до истечения deadline, iframe не остаётся; следующий Run возвращает обычный Test Report — тест на шве Runner
- [ ] Отмена во время компиляции (сигнал отменён сразу после старта) → `cancelled`; Sandbox позже не появляется; следующий Run работает — тест на шве Runner
- [ ] Уже отменённый `signal` на входе → `cancelled` сразу, ни компиляции, ни Sandbox — тест
- [ ] Отмена после того, как отчёт пришёл, ничего не меняет: возвращённый отчёт тот же, ошибок нет — тест
- [ ] Timeout без отмены работает как раньше (существующие тесты Runner зелёные)
- [ ] Экран Lesson: во время Run кнопка `■ Отмена` на месте «Запустить тесты»; нажатие показывает во вкладке «Тесты» «Запуск отменён» без красного заголовка, кнопка возвращается — UI-тест
- [ ] После отмены «Запустить тесты» с правильным решением даёт PASS — UI-тест
- [ ] `npm run typecheck`, `npm test`, `npm run test:e2e` зелёные
