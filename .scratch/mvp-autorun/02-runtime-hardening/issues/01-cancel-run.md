# 01: Отмена Run

**What to build:** пока идёт Run, на месте `▶ Запустить тесты` в тулбаре стоит `■ Отмена`. Нажатие сразу останавливает Run — и во время компиляции, и во время тестов: Sandbox уничтожается, зависшая компиляция прерывается вместе с Worker. Во вкладке «Тесты» нейтральное «Запуск отменён», кнопка снова «Запустить тесты», следующий Run работает без перезагрузки. Runner получает внешний `AbortSignal` и новый вид отчёта `cancelled`; deadline и отмена идут одним путём. См. спеку, разделы «Интерфейс Runner» и «Экран Lesson».

## Comments

- **Runner** (`packages/codda/src/runtime/runner.ts`): `run(input, { timeoutMs?, signal? })`. Deadline и отмена — один `stopWith(report)`: он abort'ит внутренний `stop`-сигнал (по нему, как в PoC, уничтожается Sandbox, а во время компиляции — `terminate()` Worker) и отдаёт `timeout` или `cancelled`. Уже отменённый `signal` — `cancelled` сразу, без `compile` и Sandbox. Новый вид `{ kind: "cancelled" }` в `TestReport` (`types.ts`); Sandbox его прислать не может — `isSandboxReport` пропускает только `tests` и `runtime-error`.
- **Экран Lesson** (`App.tsx`): пока Run идёт, в тулбаре вместо `▶ Запустить тесты` — `■ Отмена` (`AbortController` на каждый Run); «Запуск отменён» — нейтральный заголовок в Test Report; счётчика на «Тесты» после отмены нет. Состояние «Выполняется…» (кнопка disabled) из lesson-manifest/03 заменено на `■ Отмена`, его UI-тест переписан на новый.
- **TDD.** Red → green: отмена во время тестов, уже отменённый `signal`, UI-тест `■ Отмена` / «Запуск отменён». **Зелёные сразу** (поведение дал общий путь первого среза): отмена во время компиляции — что тест способен упасть, проверено мутацией (отмена без `stop.abort()` → iframe появляется позже, тест красный); отмена после отчёта; PASS после отмены на экране. Существующие тесты timeout не менялись и зелёные.
- **Оговорка теста компиляции:** `cancel.abort()` сразу после `run()` попадает в компиляцию (она идёт в Worker асинхронно), но тест этого не доказывает напрямую — только «Sandbox позже не появляется».
- **Вне критериев:** при узком окне (Vitest по умолчанию 414 px) колонки экрана Lesson зависят от ширины тулбара — смена надписи кнопки сдвигает её на 6 px; при 1280×800 места совпадают, тест проверяет там. Отмена при уходе на другой Lesson во время Run (размонтирование) не делается — Run доходит до конца, его отчёт уже никуда не попадает.
- `npm run typecheck`, `npm test` (78), `npm run test:e2e` (13) зелёные локально.
- **2026-10-04 — правки по review фичи (оркестратор).** Чекбокс «после отмены … PASS» снят: его тест выключен в тикете 02 из-за отложенного флейка (правило 7). Поведение работает в большинстве прогонов, но не гарантировано — вернуться при разборе «Отложенных проблем».
