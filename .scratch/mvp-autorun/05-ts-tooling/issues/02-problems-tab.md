# 02: Вкладка «Проблемы», статус Type Checker и смена Lesson

**What to build:** в нижней панели экрана Lesson появляется вкладка «Проблемы» (договорённость 4 в `README.md`). На вкладке счётчик ошибок, внутри список `строка:колонка — сообщение (TSxxxx)`; клик по строке ставит курсор в редактор. Пока Type Checker грузится, на вкладке «…» и текст «Проверка типов загружается». Если он не загрузился или упал — «Проверка типов недоступна», подчёркивания убираются, а редактор и Run работают. Type Checker стартует после первой отрисовки экрана, он один на сессию. При переходе к другому Lesson (`#/<lesson id>`) меняется только файл: lib JSON и `types.json` повторно не грузятся. Подробности — «Клиент Type Checker» и «Вкладка «Проблемы»» в [spec.md](../spec.md).
