# 03: Экран Lesson — тулбар, вкладки «Тесты» и «Решение», Test Report на русском, Reset

**What to build:** экран Lesson по прототипу тикета 04 Плана решений (вариант A), без дерева Course и навигации. Слева Instructions, справа тулбар `▶ Запустить тесты` · `↺ Сбросить` · `Показать решение`, редактор Workspace и нижняя панель с вкладками «Тесты» и «Решение». Test Report на русском: ✓/✗, итог `PASS`/`FAIL · N / M`, зелёный баннер при PASS, ошибки компиляции, runtime и timeout с русскими заголовками. Reset — транзакция редактора, которую откатывает `Ctrl/Cmd+Z`. Решение — только для чтения во вкладке, Workspace не трогает.

Подробности — [spec.md](../spec.md), раздел «UI». Разметку и CSS можно взять из прототипа (ветка `prototype/lesson-screen`, `src/prototype-lesson-screen/`).

## Comments

- **2026-10-04 — реализация (агент).**
  - **Экран** (`packages/codda/src/App.tsx`, `styles.css`) — вариант A прототипа без дерева: шапка `<Course> · <Lesson>` на всю ширину, слева Instructions, справа тулбар `▶ Запустить тесты` · `↺ Сбросить` · `Показать решение`, имя файла и редактор Workspace, нижняя панель (38 % высоты) с вкладками `role="tab"` «Тесты» и «Решение». Экран занимает `100vh`, колонки прокручиваются сами.
  - **Test Report:** `✓ <имя>` / `✗ <имя> — <ошибка>`, итог `PASS · M / M` / `FAIL · N / M`, при PASS сверху баннер «Все тесты пройдены»; «Ошибка компиляции» и `Строка N:M — …`, «Ошибка выполнения» и stack, «Превышено время: 5 с» и «Выполнение остановлено. Проверьте, нет ли в коде бесконечного цикла.». Регион `aria-label="Test Report"` оставлен: на нём держатся e2e. Счётчик на «Тесты» — `N/M` на зелёном/красном фоне, красный `✗` при ошибке компиляции, runtime и timeout; до первого Run — подсказка «Нажмите „Запустить тесты“» без счётчика. Пока идёт Run, на вкладке виден прошлый Test Report (критериями не задано).
  - **Решение:** второй `Editor` с `EditorView.editable.of(false)` во вкладке «Решение»; `@codemirror/state` не понадобился. Workspace не трогается, «Скрыть» нет. Run с открытой «Решение» переключает на «Тесты».
  - **Reset:** `Editor` отдаёт через `ref` (React 19) `replaceAll(text)` — одна транзакция на весь документ. **Находка:** без аннотации CodeMirror склеивает её в одну группу истории с набором, сделанным меньше 500 мс назад, и `Mod-z` откатывал Reset вместе с правкой студента. Транзакция помечена `userEvent: "reset"` (не `input.type…`/`delete…`), поэтому всегда отдельный шаг; `isolateHistory` из `@codemirror/commands` не понадобился. Тест это поймал только в полном прогоне файла (Run на прогретом Runtime быстрее 500 мс).
  - **Undo — `Mod-z` CodeMirror:** `Cmd+Z` на macOS, `Ctrl+Z` на Windows/Linux. Тест жмёт модификатор своей платформы: локально (macOS) проверен `Meta+Z`, в CI (Linux) — `Ctrl+Z`. `Ctrl+Z` на macOS не отменяет — так ведут себя все поля ввода macOS.
  - **Editor** получил `label` (`aria-label` у `contentDOM`): тесты и e2e ищут редактор Workspace по имени файла (`textbox "main.tsx"`), а Solution — по «Решение», иначе при открытой вкладке два `textbox`.
  - **e2e:** `golden-path`, `sandbox-isolation`, `course`, `dev` ищут русские надписи; в `course.e2e.ts` новый тест «другой фрагмент сбрасывает редактор, Test Report и вкладку на «Тесты»». README: сценарий и описание тестов по-русски.
  - **TDD-оговорка:** red → green для FAIL, PASS/баннер, подсказки до Run, ошибки компиляции, runtime и timeout, «Решение» (+ мутация: без `editable(false)` тест падает), переключения вкладок и Reset. **После кода:** надпись «Выполняется…» вошла в код первого среза, её тест сразу зелёный — красным подтверждён мутацией (вернул «Running…»); CSS раскладки написан в первом срезе, тест 1280×800 подтверждён мутацией (`grid-template-rows: auto 900px 38%` → падает); e2e смены фрагмента зелёный на первом прогоне — сброс даёт `key={lesson.id}` из 01b.
  - **Вне критериев:** у `toHaveTextContent` Vitest 5 на CodeMirror и на вкладке с регэкспом странное сравнение (подстрока `"return a + b;"` не находится в тексте, который её содержит) — в тестах вместо него `expect.poll(() => el.textContent)`; причину не искал. Заголовок «Instructions» над заданием остался английским (спека его так и рисует; Markdown — тикет 04). Тест таймаута ждёт настоящие 5 с — файл `App.test.tsx` стал на ~5 с дольше.
