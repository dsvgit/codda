# 03: Экран Lesson — тулбар, вкладки «Тесты» и «Решение», Test Report на русском, Reset

**What to build:** экран Lesson по прототипу тикета 04 Плана решений (вариант A), без дерева Course и навигации. Слева Instructions, справа тулбар `▶ Запустить тесты` · `↺ Сбросить` · `Показать решение`, редактор Workspace и нижняя панель с вкладками «Тесты» и «Решение». Test Report на русском: ✓/✗, итог `PASS`/`FAIL · N / M`, зелёный баннер при PASS, ошибки компиляции, runtime и timeout с русскими заголовками. Reset — транзакция редактора, которую откатывает `Ctrl/Cmd+Z`. Решение — только для чтения во вкладке, Workspace не трогает.

Подробности — [spec.md](../spec.md), раздел «UI». Разметку и CSS можно взять из прототипа (ветка `prototype/lesson-screen`, `src/prototype-lesson-screen/`).

**Blocked by:** 01

**Status:** ready-for-agent

Поведение проверяется браузерными тестами компонента экрана (Vitest browser mode, литерал `CourseData`, настоящий Run), если не сказано иное.

- [ ] Раскладка: Instructions слева, тулбар, редактор и нижняя панель справа; всё видно одновременно на экране 1280×800
- [ ] `▶ Запустить тесты` запускает Run; во время Run кнопка недоступна и показывает «Выполняется…»
- [ ] FAIL: `✓ <имя>` / `✗ <имя> — <ошибка>` и итог `FAIL · N / M`; счётчик на вкладке `N/M` красный
- [ ] PASS: итог `PASS · M / M`, зелёный баннер «Все тесты пройдены», счётчик `M/M` зелёный
- [ ] Ошибка компиляции: «Ошибка компиляции» и `Строка N:M — <сообщение>`; счётчик — красный `✗`
- [ ] Runtime-ошибка: «Ошибка выполнения» и stack; timeout: «Превышено время: 5 с» и подсказка про бесконечный цикл
- [ ] До первого Run во вкладке «Тесты» — подсказка «Нажмите „Запустить тесты“», счётчика нет
- [ ] `Показать решение` открывает вкладку «Решение»: Solution в редакторе только для чтения (ввод не меняет текст), Workspace над ним не изменился
- [ ] Run при открытой вкладке «Решение» переключает на «Тесты»; переключение вкладок не теряет Workspace и последний Test Report
- [ ] `↺ Сбросить` без подтверждения возвращает Starter; `Ctrl+Z` (и `Meta+Z`) после этого возвращает код студента одним шагом
- [ ] Reset не стирает последний Test Report
- [ ] Смена Lesson через фрагмент сбрасывает редактор, Test Report и вкладку на «Тесты» (e2e)

- [ ] `npm run typecheck`, `npm test`, `npm run test:e2e` зелёные
