# 04: Run: импорт вне точек входа, пропавший и испорченный артефакт

**What to build:** Ошибки Run, связанные с Dependency Artifact, понятны студенту. Импорт specifier'а, которого нет в `imports` (или у Course нет артефакта), даёт compile-error на строке импорта «Импорт "<specifier>" не предусмотрен заданием». 404 на `importmap.json` или файл артефакта — «Курс обновился, перезагрузите страницу». Прочая ошибка загрузки (сеть, `integrity`) — «Не удалось загрузить зависимости курса: <причина>». Код студента в этих случаях не исполняется, следующий Run загружает заново. Тексты и вид отчёта — в [спеке](../spec.md).

## Comments

- **Устройство.** Всё в `compiler.worker.ts`. `onResolve` разрешает bare specifier через артефакт; нет в `imports` или у Course нет артефакта (`importMap` не передан) — ошибка esbuild «Импорт "<specifier>" не предусмотрен заданием», esbuild ставит её на строку импорта, а колонку и строку в Workspace отдаёт прежний путь `runtime-hardening/04`. Ошибка загрузки запоминается в `loadError`, и тогда Run возвращает ровно одну compile-error без строки, остальные ошибки esbuild отбрасываются. Неудачная загрузка не кэшируется (так было с 01), поэтому следующий Run грузит заново.
- **404 под `integrity` (обход по правилу 6).** Chrome отклоняет `fetch(url, { integrity })` с ответом 404 как сетевую ошибку (`Failed to fetch`): тело 404 не совпадает с hash. Поэтому после провала `fetch` Worker делает `HEAD` без `integrity` (`cache: "no-store"`): 404 — «Курс обновился, перезагрузите страницу», иначе «Не удалось загрузить зависимости курса: <путь>: <сообщение браузера>». Ответ 404 без провала (`response.status === 404`) обрабатывается так же. Свою проверку hash через `crypto.subtle` не делали — проверку оставляем браузеру, как в спеке.
- **Как сломать артефакт в тестах.** Команда Vitest `failRequests(pattern, response?)` в `vite.config.ts` теперь, кроме `abort()`, умеет `route.fulfill(response)`: 404 на `importmap.json` или chunk, подменённое тело `react-*.js` (тогда не сходится `integrity`). Перед каждым таким тестом Worker сбрасывается (`coldCompiler`), чтобы артефакт не был уже в памяти. Копия артефакта во временной папке, как предлагала спека, не понадобилась.
- «Код студента не исполнен»: в тесте с подменённым файлом код студента пишет в Console, а `onConsole` пуст и iframe нет.
- Причина у «Не удалось загрузить…» — путь файла и сообщение браузера (`Failed to fetch` при сети и при `integrity` одинаково, Chrome их не различает) — формат в спеке не задан.
- Тесты Runner написаны до кода и увидены красными (7 тестов). UI-тест «Импорт … не предусмотрен заданием» с подчёркиванием дописан после кода Worker и сразу был зелёным: UI не менялся, compile-error идёт прежним путём.
