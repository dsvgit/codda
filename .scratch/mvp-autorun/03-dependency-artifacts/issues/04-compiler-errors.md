# 04: Run: импорт вне точек входа, пропавший и испорченный артефакт

**What to build:** Ошибки Run, связанные с Dependency Artifact, понятны студенту. Импорт specifier'а, которого нет в `imports` (или у Course нет артефакта), даёт compile-error на строке импорта «Импорт "<specifier>" не предусмотрен заданием». 404 на `importmap.json` или файл артефакта — «Курс обновился, перезагрузите страницу». Прочая ошибка загрузки (сеть, `integrity`) — «Не удалось загрузить зависимости курса: <причина>». Код студента в этих случаях не исполняется, следующий Run загружает заново. Тексты и вид отчёта — в [спеке](../spec.md).

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Тест Runner: `import "lodash"` (пакет не в артефакте) в коде студента — compile-error с текстом «Импорт "lodash" не предусмотрен заданием» и строкой/колонкой импорта; то же для subpath установленного пакета, которого нет в точках входа (`react-dom/server`)
- [ ] Тест Runner: Course без артефакта (`deps: null`) и bare-импорт — та же compile-error
- [ ] Тест Runner: `importmap.json` отвечает 404 — compile-error «Курс обновился, перезагрузите страницу» без строки; то же, если 404 на chunk
- [ ] Тест Runner: файл артефакта подменён (`integrity` не совпадает) — compile-error «Не удалось загрузить зависимости курса: …»; код студента не исполнен (тест с побочным эффектом в коде студента это видит)
- [ ] Тест Runner: после ошибки загрузки исправленный артефакт загружается на следующем Run без перезагрузки страницы, Run даёт PASS
- [ ] Ошибки показываются в UI так же, как прочие compile-error (вкладка «Тесты»); «Импорт … не предусмотрен заданием» подчёркнут на строке импорта (подчёркивание из `runtime-hardening/04`)
