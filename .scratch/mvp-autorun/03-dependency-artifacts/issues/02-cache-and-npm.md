# 02: Кэш артефакта по hash, правила npm и проверки `package.json`

**What to build:** Повторный `codda build` без изменений в `package-lock.json` и импортах не запускает ни npm, ни esbuild: артефакт берётся из `.codda/deps/<hash>/`. npm запускается по правилу тикета 05: при `CI=true` всегда `npm ci`, локально — только если `node_modules` нет или они расходятся с `package-lock.json`. Ошибка `npm ci` показывается выводом npm с префиксом `npm ci:` и одной подсказкой. Диапазон версий, отсутствующий lockfile и Course без импортов пакетов обрабатываются по [спеке](../spec.md).

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Сборка пишет во временную папку в `.codda/deps/` и переименовывает её в `<hash>/` только целиком; при наличии `.codda/deps/<hash>/` npm и esbuild не запускаются
- [ ] Одна строка вывода: `Зависимости: deps/<hash> — собраны за N с` или `— из кэша`
- [ ] Тест CLI: второй `codda build` той же фикстуры печатает «из кэша» и даёт тот же `<hash>` и побайтно те же файлы в выходе
- [ ] Тест CLI: новый импорт пакета в одном Lesson меняет `<hash>` и пересобирает артефакт; правка Lesson без изменения импортов — нет
- [ ] Тест CLI: брошенная временная папка от прерванной сборки не считается артефактом, следующий `codda build` собирает заново
- [ ] Локально npm не вызывается, если `node_modules/.package-lock.json` совпадает с `package-lock.json` по версиям пакетов; иначе или без `node_modules` — `npm ci`. При `CI=true` — всегда `npm ci` (при промахе кэша)

- [ ] Тест CLI: `CI=true`, `package.json` и `package-lock.json` не согласованы — код `1`, строки вывода npm с префиксом `npm ci: `, затем строка «запустите `npm install` локально и закоммитьте `package-lock.json`»; артефакта нет
- [ ] Тест CLI: версии `^19.3.0`, `~1.0.0`, `*`, `latest` в `dependencies` — по ошибке на каждый пакет с его именем, все сразу, код `1`; `1.0.0-beta.1` допустима; диапазон в `devDependencies` не ошибка и пакет из `devDependencies` в артефакт не попадает
- [ ] Тест CLI: нет `package-lock.json` (или `package.json`) — ошибка с подсказкой «запустите `npm install`», код `1`
- [ ] Тест CLI: Course без импортов пакетов — npm не запускается, папки `deps/` в выходе нет, `"deps": null` в `course.json`; Run такого Course проходит (Runner или e2e)
