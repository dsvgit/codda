# 03: Дерево Course слева

**What to build:** Слева от Instructions появляется колонка с деревом Course (раскладка «IDE» из тикета 04 Плана решений): название Course, Module заголовками, под каждым — его Lesson по порядку `course.yaml` с `title` из frontmatter. Lesson — ссылка `#/<lesson id>`, клик открывает его через тот же механизм фрагмента, что тикет 01. Текущий Lesson выделен и помечен `aria-current="page"`. Кнопка `«` сворачивает дерево в узкую полосу, `»` разворачивает; состояние не сохраняется и живёт до перезагрузки. Module сами не сворачиваются. Прогресс (✓, «Пройдено N из M») добавляет тикет 04. См. [спеку](../spec.md).

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Дерево показывает название Course, все Module и все Lesson в порядке `course.yaml`, у Lesson — `title`
- [ ] Клик по Lesson меняет фрагмент и открывает Lesson (с записью в истории); выделение и `aria-current` переезжают на него, в том числе при `← Предыдущий` / `Следующий →` и «Назад» браузера
- [ ] `«` сворачивает дерево, редактор и Instructions занимают освободившуюся ширину; `»` разворачивает; доступные названия кнопок — «Свернуть список уроков» / «Развернуть список уроков»
- [ ] e2e (offline, `dev` и `pages`): клик по третьему Lesson в дереве → его заголовок и фрагмент; свернуть → Lesson в дереве не видны → развернуть
- [ ] Компонентный тест (фикстура из двух Module): оба Module с их Lesson по порядку, текущий Lesson помечен `aria-current`
